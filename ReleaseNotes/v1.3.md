# What's New in Cinch 1.3

## MCP server for AI agents

Cinch now ships **`cinch-mcp`**, an [MCP (Model Context Protocol)](https://modelcontextprotocol.io) server that lets AI assistants — Cline, Claude Code, Claude Desktop and friends — browse, create, edit and extract archives using the exact same engines as the app (libzip for zip, including AES-256 passwords; the built-in ustar/gzip engine for tar).

- Bundled with the app at `Cinch.app/Contents/MacOS/cinch-mcp` (universal arm64 + x86_64), so one install gives you both the GUI and the server
- Ten tools: `archive_list`, `archive_read`, `archive_extract`, `archive_create`, `archive_add`, `archive_write_file`, `archive_delete`, `archive_rename`, `archive_new_folder`, `archive_set_password`
- Supports zip and tar / tar.gz; passwords are passed per tool call and never persisted
- Unsafe entry paths (`..`) are rejected on extraction

Point your MCP client at the bundled binary, e.g. in `cline_mcp_settings.json`:

```json
{
  "mcpServers": {
    "cinch": { "command": "/Applications/Cinch.app/Contents/MacOS/cinch-mcp" }
  }
}
```

See the README's *MCP server* section for details.
